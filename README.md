# Возрастные контакты — 108 лет

Независимый Streamlit-калькулятор по данным рождения.

## Запуск

1. Откройте https://share.streamlit.io/ и войдите через GitHub.
2. Нажмите **Create app** → **Deploy a public app from GitHub**.
3. Выберите репозиторий `t94765235065-crypto/astro-108-calculator.` и ветку `main`.
4. Укажите главный файл `app.py` и нажмите **Deploy**.

Примечание: для бесплатной публикации через Streamlit Community Cloud обычно требуется публичный репозиторий. Не загружайте в репозиторий персональные данные клиентов.

## Точность

Натальные долготы рассчитываются через pyswisseph с Moshier-эфемеридами; координаты через Nominatim; часовые пояса — timezonefinder + IANA. Контакты вычисляются для малых точек жизни и кризиса, периоды по условному орбису. Хирон, Селена и Жребий Фортуны пока вводятся вручную. Требуется сверка с Астропроцессором на контрольных картах до использования в работе с клиентами.
